# AFKade

Relaxing mini games for World of Warcraft — for flight paths, boat rides, queues and AFK breaks.

*Entspannte Minispiele für Flugrouten, Schiffsfahrten, Warteschlangen und AFK-Pausen.*

## Games

- **Untangle**
- **Pipes**
- **Sprint**
- **Hunt**
- **Quiz**

## Installation

1. Download or clone this repository.
2. Place the `AFKade` folder in `World of Warcraft/_retail_/Interface/AddOns/`.
3. Restart the game or run `/reload`.

Open AFKade via the minimap button or the addon compartment.
